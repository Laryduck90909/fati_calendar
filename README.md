# fati calendar — تطبيق Flutter

تطبيق تقويم طالب: جدول أسبوعي قابل للتعديل + منبهات صوتية/صامتة + مذكرات كتابية.

## المميزات
- جدول أسبوعي قابل للتعديل (اضغط أيقونة القلم بجانب أي موعد)
- 3 سمات: البحر البنفسجي، المحيط اللازوردي، البرق البنفسجي
- منبهات صوتية أو صامتة لكل مهمة
- مذكرات كتابية مع حفظ تلقائي
- أيقونة تطبيق مخصصة

## البناء على GitHub Actions
1. ارفع الملفات إلى المستودع
2. Actions ← Build APK ← Run workflow
3. حمّل Artifacts بعد اكتمال البناء

## تعديل الجدول
عدّل ملف `assets/schedule.json` ثم أعد البناء.
